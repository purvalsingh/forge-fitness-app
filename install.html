Personal fitness operating system

Install FORGE

Two ways to put it on your phone. Both run the same build and share the same account.

Android app

A signed APK, 0.9 MB. Runs without any browser chrome and appears in your app drawer.

Download APK
  1. Tap Download APK. Your browser will warn that APKs can be harmful — that warning appears for every file it did not get from the Play Store.
  2. Open the downloaded file. Android asks to allow installs from this source; grant it once.
  3. Install, then open FORGE from your app drawer.

Or add to home screen

No install prompt, no APK. In Chrome or Brave: menu → Add to Home screen. It opens standalone, exactly like the app.

Open FORGE

Updates to the web app reach both versions automatically — the app is a shell around the same site. Only a change of address needs a fresh APK.
